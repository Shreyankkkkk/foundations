# References — Arduino / C Programming

## Tools

- **Wokwi** — free browser-based Arduino simulator, used for all exercises so far (no physical hardware required, zero risk of frying real parts).
  https://wokwi.com

## Component Documentation

- **Wokwi Pushbutton Reference** — explains the 2-contact / 4-leg wiring logic, `INPUT_PULLUP` behavior, and button bouncing simulation. This is what resolved the wiring issue in Exercise 02.
  https://docs.wokwi.com/parts/wokwi-pushbutton
