## Rules
- One course at a time. No side tracks. Finish it, understand it, get the certificate if one exists, log it on GitHub, then move on.
- I type all code myself. AI explains, reviews, and answers; it does not write my code.
- Each step ends with GitHub notes + exercises (a project where listed).
- Uni runs alongside because it has to. In heavy uni sessions (Year 3 ECTE351, Year 4 Thesis) I pause or slow the self-study step; I do not add a second one.
- Time estimates are guesses. Move on when finished, not when the date arrives.
