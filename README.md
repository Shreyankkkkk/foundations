A personal knowledge base documenting everything I study, build, and achieve — programming, mathematics, finance, and engineering — as I build toward a career in quantitative finance.

This isn't a portfolio of polished final products. It's a working library: notes from what I'm learning, projects I've built (including early, rough versions), certificates I've earned, and a running log of the journey. If you're looking at this, you should be able to tell exactly what I know, what I've built, and what I'm working on next.
