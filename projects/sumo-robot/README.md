# Sumo-Robot (SumoX-26)

Autonomous sumo robot (Arduino UNO Q, 20x20 cm, 3 kg) built for the Dubai TechBots League SumoX-26. Competed 2026-10-04 and was eliminated after three matches.

Start with `STATE.md` (result, constants with calculations, hardware, rules), then `Retrospective.md` (what worked and what didn't, by stage). `LOG.md` is the history.

| Folder | Holds |
|---|---|
| `docs/specs/` | wiring, strategy and reference documents |
| `docs/rulebook/` | competition rulebook and briefing slides |
| `design/` | `cad-v1` and `cad-v2` models, `parametric` wedge and deck scripts |
| `firmware/strategy/` | firmware versions `v1.0` to `v2.4` (v2.4 was on the board), `CodeGuide.md` |
| `firmware/tests/` | sensor, motor and calibration sketches |
| `notes/` | notes, dated scans (`scans/`), and per-chat summaries (`chat-summaries/`) |
