# frontend/sample_uploads

Synthetic files for trying the **Add Documents** page. Nothing here is real plant data.

| File | What it is |
|---|---|
| `sample_sop_battery_charging.pdf` | A SOP as PDF (numbered lines become steps) |
| `sample_sop_die_change.docx` | A SOP as Word |
| `sample_notes.csv` | Notes as CSV |
| `sample_notes_logbook.txt` | Notes as a text logbook, one per dated line |

Benchmark scores only make sense for the backend's own notes, because `answer_key.json` belongs to them.
