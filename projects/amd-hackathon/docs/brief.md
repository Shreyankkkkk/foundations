## What the program is
Beginner-oriented AMD GPU learning path with a bi-weekly challenge cadence. Points (XP) come from AI Academy courses, building and submitting projects, writing blogs/tutorials, Discord help, and referrals. Building is the highest-weighted category. Skills covered: model serving, MCP, agents and tool calling, GPU resource use, OCR, RAG, web-scraping agent, multi-agent software engineering, fine-tuning for a novel game.

## XP table (event page, SOURCED)
Onboarding: join Discord +50, complete AMD profile +100. Learning: Academy course +150 each, 5-course bonus +100, 10-course bonus +100, ROCm certification +150. Building: first project +50, connect GitHub repo +5, demo +150, complete project +200, open-source project +200, participate in an AMD hackathon +300, build with AMD technologies +250, milestone +100 (max 3 per project). Community: Discord answer +5, like +2, accepted solution +50, Community Contributor badge +250. XP updates weekly (Fridays).
