# Git & GitHub

Core version control skills, covering everything from the mechanics of how Git tracks changes to the collaborative workflows used on GitHub.

## What's covered

**Git fundamentals**
Repository structure, the commit lifecycle, staging area vs. working directory, HEAD and branch pointers, commit hashes.

**Branching & merging**
Creating and switching branches, merging strategies, rebasing, cherry-picking, and recovering lost work via backup branches.

**History management**
Interactive rebase, squashing and rewording commits, cleaning up history, atomic commits, and commit message conventions.

**GitHub workflows**
Pull requests, issues, labels, projects, releases, tags, GitHub Actions, and basic CI/CD concepts.

**Repository management**
`.gitignore` patterns, commit hooks, branch naming conventions, and team collaboration workflows.

## Notes

Detailed notes for each topic live in [`notes/`](./notes/), organized by subject.

## Why this came first

Git was deliberately the first thing learned before writing any real project code — every project and note in this repository is tracked and versioned from the start, rather than retrofitted later.
