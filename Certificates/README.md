# Certificates

Every certificate earned, indexed here and filed under the matching subfolder by domain.

## Index

| Certificate | Issuer | Date | Domain | File |
|---|---|---|---|---|
| Python Developer Certification | freeCodeCamp | [month] 2026 | Programming | [`programming/freecodecamp-python-developer.pdf`](./programming/) |

## Structure

```
certificates/
├── programming/       # language & CS certifications
├── finance/            # CFA and other finance credentials
└── miscellaneous/      # everything else
```

## Adding a new certificate

1. Drop the certificate file (PDF/image) into the matching domain subfolder.
2. Add a row to the table above — keep it in reverse-chronological order (newest first).
3. Use a consistent filename pattern: `issuer-credential-name.pdf` (lowercase, hyphenated).
